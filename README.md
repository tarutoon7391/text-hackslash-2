# text-hackslash-2

ターン制テキストハックアンドスラッシュRPG（周回・収集・厳選型）。
初代 text-hackslash の後継作。**フェーズ4：職業レベル・合成（+値と引き継ぎ）・端末内セーブ** まで実装済み。

## フェーズ4の内容（2026-11：成長と合成）

- 職業レベル・経験値（職業ごと）。レベルでステータスが成長
- 防具・アクセ・エンチャント12種・+値を戦闘に反映（画面のステータス＝戦闘のステータス）
- 合成：欠片や他の装備を素材に+値を上げる。親装備のスキル／エンチャントを選んで引き継ぐ（旧：抽出・移植を置き換え）
- ドロップを素材メインに変更（欠片は毎回、装備は雑魚15%・ボス確定）
- 端末内セーブ（localStorage。サーバー・DB不要）
- UI：サイバー／ターミナル風テーマ、ドット絵の敵＋敵の上のHPバー・ダメージ数字、スキル1タップ発動、
  装備一覧のクイック装備・絞り込み・並べ替え、探索中はフッターナビ非表示

## フェーズ3の内容（パート1〜2）

- 装備管理画面：4スロット付け替え・装備込みステータス合算・スキル/エンチャントの抽出（装備破壊）と移植
- 初期装備：新規プレイ時に武器6種＋防具1（コモン相当・無属性・ドロップより弱い固定性能）を自動付与
- 職業デフォルト初期装備：初回の職業選択時のみ職業に合う初期武器＋初期防具を自動装備。
  転職では防具・アクセを常に維持し、武器は互換性がなければ空にするだけ（自動差し替えなし）
- 装備の入手・変更をインベントリ経由に一本化（テスト用サンプル武器を廃止。出発武器は装備スロットから）
- フッター固定ナビ（ダンジョン／装備／辞典）＋主要画面のスクロール解消（1画面完結レイアウト）

## フェーズ2の内容

- エンドレスタワー＋チェックポイント制（5階ごと、ボス撃破で次を解放）
- 属性ゾーンテーマ（5階ブロックごとに火→水→雷→土→光→闇を巡回）
- 階層スケーリングする敵生成（雑魚1〜4階目／ボス5階目）
- ドロップ生成：レア度抽選（雑魚/ボス別）・武器/防具/アクセサリー・
  GDD 9.2スキル抽選・GDD 10.2エンチャント抽選（青天井/渋カーブ・部位別重み）
- 勝利リザルト画面・インベントリ（React state。DB保存はフェーズ3）
- ロビーでチェックポイント選択＋ドロップ武器の装備

## フェーズ1の内容

- 6属性の相性システム（火→土→雷→水→火サイクル、光⇔闇相互弱点、耐性0.5倍）
- 状態異常5種（火傷・凍結・感電・混乱・呪い）のスタック×残りターン2軸管理

- GDD 9.2の抽選ルールを再現した武器生成関数（フェーズ2のドロップでそのまま使用）
- モバイルファーストの1画面完結戦闘UI
- 初級職5種＋テスト武器12本＋テスト敵5体

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド（dist/）
npm start        # ビルド済みdistを配信（本番用）
npm run smoke    # 戦闘エンジンのスモークテスト
npm run smoke:dungeon  # ダンジョン・ドロップのスモークテスト
```

## Railwayデプロイ

1. Railwayで **New Project → Deploy from GitHub repo** を選ぶ
2. このリポジトリ（tarutoon7391/text-hackslash-2）を選択するだけでOK
   - ビルド：`npm install && npm run build`（自動検知）
   - 起動：`npm start`（express が dist/ を配信）
3. 環境変数・DBの設定は**一切不要**（フェーズ1はフロントのみで完結）

## 構成

```
src/
  data/            # 全ゲームデータ（ハードコーディング禁止、ここに集約）
    elements.js        # 6属性と相性表
    statusEffects.js   # 状態異常5種（dispellableフラグ付き）
    skills_normal.js   # 無属性スキル168個
    skills_elemental.js# 属性スキル48個
    weaponTypes.js     # 6武器種
    jobs.js            # 初級職5種
    rarities.js        # レア度とスキル抽選ルール（GDD 9.2）
    battleConfig.js    # 戦闘定数（会心・一致ボーナス・+値の仮式など）
    enemies.js         # テスト敵5体
    starterEquipment.js# 初期装備一式（武器6種＋防具1。コモン相当・無属性）
  systems/
    battleEngine.js    # 戦闘エンジン（UI非依存・Nodeでも動く）
    weaponGenerator.js # 武器生成（GDD 9.2抽選。フェーズ2ドロップで再利用）
  components/          # React UI（モバイルファースト）
test/
  battle-smoke.js  # スモークテスト（node test/battle-smoke.js）
server.js          # Railway用の静的配信サーバー
```
